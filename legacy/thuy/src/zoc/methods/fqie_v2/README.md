# FQIE v2 decision core (experimental / historical)

This is an archived research component, not a promoted method and not a
self-contained GPU reproduction. The CPU decision core is packaged as
`zoc.methods.fqie_v2`. Historical GPU commands require external dependencies
and artifacts that are intentionally not included.

This package implements a frozen, remove-only decision on complete candidate
and evidence JSON files. It is **not** a promoted FQIE selector. The H2/H3
component gates remain open, and the current ledgers lack query-free captions
and two-view descriptor scores for every FSC candidate.

Run with:

```bash
PYTHONPATH=src python3 -m zoc.methods.fqie_v2.run candidates.json evidence.json config.json output.json
PYTHONPATH=src python3 -m unittest zoc.methods.fqie_v2.test_core -v
```

`config.json` must contain a finite `tau` and SHA256 hashes of both exact input
files under `input_sha256.candidates` and `input_sha256.evidence`. Candidates
and evidence each contain an `items` array with the same unique
`candidate_id`s. Every evidence item needs `caption_status`, `compatibility`,
and `views.full`/`views.context`, each with `descriptor_cosine`, `query_cosine`,
and positive `alpha_pixels`. The decision is `REMOVE` only for a valid caption,
explicit reviewed contradiction, valid views, and a strict minimum margin
above `tau`. All other cases are `KEEP_UNVERIFIED`. An output file is
write-once and records the complete decision ledger and original boxes.

The full FSC development manifest is generated by `manifest.py`: 100 primary
query items with frozen M0/A4 candidates, plus 111 verified-absent query items
with all 6,942 M0 boxes. It records source overlap and never opens GT. The
long GPU stages in `gpu.py` encode rectangle regions, create query-free native
CycleGRPO captions, and score descriptor/query with synchronized Alpha-CLIP
full and context views. Each candidate has a hashed, write-once file so a
restarted command resumes. `freeze` requires every candidate and hashes every
output before `assemble` or `evaluate` can proceed.

The following commands are historical execution records for a GPU with enough free VRAM for the local
CycleGRPO 4B model (prior peak was 9.166 GiB). They may take much longer than
five minutes on 12,173 candidates. They are not independently executable from
this archive: `external/AlphaCLIP`, `cyclegrpo_venv_pc170/`, candidate
manifests, checkpoints, and runtime outputs are not released. Run from the
original ZOC workspace only after restoring those dependencies. Do not put
`set -e` in an interactive terminal: it closes the terminal on the first
error and hides the traceback. The first three
commands can be repeated after interruption. `--max-items 1` gives a bounded
technical smoke for each stage; omit it for the complete run.

```bash
M=target_aware_counting/output/fqie_v2_fsc_dev_20261104_v1/candidates.json
O=target_aware_counting/output/fqie_v2_fsc_dev_20261104_v1/gpu
FQIE_PYTHON="${FQIE_PYTHON:-python3}"
FQIE_EXTERNAL_ROOT="${FQIE_EXTERNAL_ROOT:?set path to the external Alpha-CLIP/CycleGRPO dependencies}"
export ZOC_FQIE_RUNTIME_ROOT="${ZOC_FQIE_RUNTIME_ROOT:?set path to the external FQIE runtime artifacts}"
PYTHONPATH="$FQIE_EXTERNAL_ROOT/AlphaCLIP:src" "$FQIE_PYTHON" -m zoc.methods.fqie_v2.gpu encode "$M" "$O"
PYTHONPATH="$FQIE_EXTERNAL_ROOT/AlphaCLIP:src" "$FQIE_PYTHON" -m zoc.methods.fqie_v2.gpu caption "$M" "$O"
PYTHONPATH="$FQIE_EXTERNAL_ROOT/AlphaCLIP:src" "$FQIE_PYTHON" -m zoc.methods.fqie_v2.gpu compare "$M" "$O"
PYTHONPATH="$FQIE_EXTERNAL_ROOT/AlphaCLIP:src" "$FQIE_PYTHON" -m zoc.methods.fqie_v2.gpu freeze "$M" "$O"
```

Do not treat a partly completed stage as a result. To assemble decisions, an
independent reviewer must first provide a JSON file with status
`REVIEWED_DISJOINT_PAIRS` and rows containing `descriptor`, `query`,
`reviewer_id`, and `review_date`. Without reviewed disjoint pairs, use
`no_reviewed_pairs.json` for an explicit no-op parity run. The conservative rule
then keeps all candidates as unverified. The existing Alpha target-only and
Cycle unary probes cannot be substituted for two-view descriptor evidence.
Calibration and selector promotion remain blocked by the open H2 gate.

After GPU freeze, the CPU-only parity/evaluation sequence is:

```bash
M=target_aware_counting/output/fqie_v2_fsc_dev_20261104_v1/candidates.json
O=target_aware_counting/output/fqie_v2_fsc_dev_20261104_v1/gpu
D=target_aware_counting/output/fqie_v2_fsc_dev_20261104_v1
PYTHONPATH=src python3 -m zoc.methods.fqie_v2.assemble "$M" "$O" src/zoc/methods/fqie_v2/no_reviewed_pairs.json "$D/evidence.json"
PYTHONPATH=src python3 -m zoc.methods.fqie_v2.lock_config "$M" "$D/evidence.json" "$D/config.json" --tau 0
PYTHONPATH=src python3 -m zoc.methods.fqie_v2.run "$M" "$D/evidence.json" "$D/config.json" "$D/predictions.json"
PYTHONPATH=src python3 -m zoc.methods.fqie_v2.evaluate "$M" "$O/freeze.json" "$D/evidence.json" "$D/predictions.json" "$D/evaluation"
```
