# Reproducibility checklist

- [ ] Dataset version and split recorded.
- [ ] Cohort/image IDs recorded.
- [ ] Model checkpoint and SHA256 recorded.
- [ ] Source commit recorded.
- [ ] Exact command recorded.
- [ ] Seed recorded or marked not applicable.
- [ ] Evaluation protocol and denominator recorded.
- [ ] Raw metric file linked.
- [ ] Qualitative examples linked where available.
- [ ] Result status marked as audited, reported-pending-audit, diagnostic, or invalid.
